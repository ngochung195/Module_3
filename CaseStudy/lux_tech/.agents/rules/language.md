# Quy Tắc Ngôn Ngữ Thông Báo System & UI

- **Tất cả các thông báo xuất ra màn hình (UI/JSP/HTML)**, thông báo lỗi validation, toast/alert, và log ghi ra console (`System.out.println`, `System.err.println`, loggers) **BẮT BUỘC** phải sử dụng **Tiếng Việt** rõ ràng, dễ hiểu.
- Ví dụ:
  - `✔ Kết nối CSDL thành công!` (thay vì `✔ Database Connection Successful!`)
  - `✘ Kết nối CSDL thất bại!` (thay vì `✘ Database Connection Failed!`)
  - `Không tìm thấy file db.properties` (thay vì `unable to find db.properties`)
