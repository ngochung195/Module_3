# Thư mục lưu trữ hình ảnh sản phẩm (Product Images)

- Lưu các file ảnh sản phẩm vào thư mục này: `src/main/webapp/assets/images/products/`
- Ví dụ: `iphone17.png`, `macbook.jpg`, `airpods.png`, v.v.
- Khi thêm hoặc sửa sản phẩm trên giao diện, bạn có thể điền:
  1. Tên file ảnh trong thư mục này (ví dụ: `iphone17.png`)
  2. Hoặc một URL ảnh trực tuyến (bắt đầu bằng `http://` hoặc `https://`)
- Nếu sản phẩm chưa có ảnh hoặc tên ảnh trống, hệ thống sẽ tự động hiển thị Icon Bootstrap theo danh mục tương ứng.
